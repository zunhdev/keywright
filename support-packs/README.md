# Keyboard support packs

Each directory here is a support pack: what Keywright knows about a keyboard model that the keyboard can't report itself, such as its stock keymap and how to unlock it (tech spec §10). Keywright embeds every pack when it's built.

- [`keebart-sofle-choc-pro-bt/`](keebart-sofle-choc-pro-bt/): Keebart's Sofle Choc Pro BT.

To add one, see [How to add a keyboard support pack](../docs/contributing/support-packs.md).
