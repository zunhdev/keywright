# Keyboard shortcuts

Everything in Keywright works from the keyboard. Tab moves between the toolbar, the layers, the keyboard and the inspector.

## On the keyboard

These work while the keyboard in the middle of the window has the focus, so they never get in the way of typing in a field.

| Keys       | What they do                                                       |
| ---------- | ------------------------------------------------------------------ |
| Arrow keys | Select the nearest key in that direction, across both halves.      |
| Return     | Go to the inspector's Action button, for the selected key.         |
| R or ⌘R    | Record a shortcut for the selected keys.                           |
| T          | Make the selected keys the same as the layer below.                |
| Delete (⌫) | Make the selected keys do nothing. The first time, Keywright asks. |
| ⌘C, ⌘V     | Copy a key's action, and paste it onto the selected keys.          |
| ⌘A         | Select every key.                                                  |
| Escape     | While recording, stop. While dragging a key, cancel.               |

## In the menus

| Keys     | Menu item                            |
| -------- | ------------------------------------ |
| ⌘,       | Keywright › Settings…                |
| ⌘O       | File › Import…                       |
| ⇧⌘E      | File › Export…                       |
| ⇧⌘B      | File › Backups…                      |
| ⌘Z       | Edit › Undo                          |
| ⇧⌘Z      | Edit › Redo                          |
| ⌘F       | Edit › Find: search keys             |
| ⌘S       | Keyboard › Save to Keyboard          |
| ⇧⌘R      | Keyboard › Review Changes            |
| ⌘R       | Keyboard › Record Shortcut           |
| ⌃⌘S      | View › Hide or Show Layers           |
| ⌥⌘0      | View › Hide or Show Inspector        |
| ⌘1 to ⌘9 | View › Layer 1 to 9                  |
| ⌘+, ⌘−   | View › Zoom In, Zoom Out             |
| ⌘0       | View › Actual Size                   |
| ⌃⌘F      | View › Enter Full Screen             |
| ⌘/       | Help › Keyboard Shortcuts: this page |

While a text field has the focus, such as search or a layer's name, ⌘Z, ⌘C, ⌘V and ⌘A edit its text instead.

## In search

| Keys         | What they do                  |
| ------------ | ----------------------------- |
| Return       | Select the next matching key. |
| Shift-Return | Select the one before.        |
| Escape       | Clear the search.             |

## In the key picker

| Keys          | What they do                                          |
| ------------- | ----------------------------------------------------- |
| Type          | Search every key. ↓ goes from the search to the keys. |
| Arrow keys    | Move between keys, by where they are.                 |
| Return, Space | Choose the key.                                       |
| Escape        | Clear the search, then close the picker.              |
