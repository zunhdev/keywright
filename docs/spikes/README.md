# Spike reports

Each file here reports one hardware or platform spike from tech spec §15: what was tried, what was measured, and what Keywright does as a result. The tech spec records the decisions; these reports keep the evidence.

| Spike                   | Question                                                  | Outcome                                                                                                                                                                         |
| ----------------------- | --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [S1](s1-usb-serial.md)  | USB port identity, probe timing, safe frame size, locking | No write pacing; one write per frame of at most 30 bytes; `EOF` after a timeout; renames retried (KEY-95)                                                                       |
| [S2](s2-bluetooth.md)   | Bluetooth LE on macOS: `bluest` or `btleplug`             | `bluest` (ADR-0009); 27-byte indications, so timeouts count from the last bytes received; renames retried there too                                                             |
| [S3](s3-battery.md)     | The battery over Bluetooth, polling or notifications      | Readable while macOS holds the keyboard, also while editing over USB; subscribe, don't poll; stock firmware: left half only                                                     |
| [S4](s4-right-half.md)  | Telling the right half apart on USB                       | Silent, and no keyboard (HID) interface on its USB device; `serialport` misses its product string, so read the interfaces with `nusb` (KEY-99)                                  |
| [S5](s5-locking.md)     | The idle lock, switching connections, the other output    | Any request puts the idle lock off (612 s); switches lock and leave the old connection quiet; changes survive locks but not sleep; ask for the lock state while locked (KEY-97) |
| [S6](s6-uf2.md)         | Updating the firmware through the UF2 drive               | Both halves updated; the drive's USB serial number says which half; `EIO` on the last write, then the drive gone and the half back, is success; macOS asks to allow each half   |
| [S7](s7-mac-actions.md) | Mac actions, keys that don't work on a Mac, Globe         | 24 presets work on macOS 27, offered per version (15 and 26: KEY-98); 12 Windows and Linux keys do nothing; Globe through `hidutil`, not Modifier Keys                          |
